# 컴학내전 데이터 수집기

롤 클라이언트(LCU)에서 내전(커스텀 게임) 결과를 읽어 **로컬에 백업한 뒤** 사이트로 업로드합니다.
Python 3.8+ 표준 라이브러리만 사용합니다 (GUI는 내장 tkinter). Windows 전용.

사이트 상단의 **수집기** 버튼으로 내려받으면 서버 주소가 채워진 ZIP이 내려옵니다.
ZIP 안에는 비밀값이 들어 있지 않습니다. 업로드 토큰은 각자 PC에서 한 번 입력합니다.

## 처음 한 번 설정 (약 2분)

1. [python.org/downloads](https://python.org/downloads) 에서 Python 설치 — **"Add Python to PATH" 체크**
2. ZIP을 지워지지 않을 폴더에 풉니다 (예: `문서\내전수집기`)
3. `내전수집기.bat` 더블클릭 → **[업로드 토큰 설정]** → 사이트 관리자에게 받은 토큰 입력
   → `✅ 서버 연결 및 토큰 확인 완료` 가 로그에 뜨면 성공
4. **"Windows 로그인 시 자동 실행"** 체크 (또는 `자동실행_등록.bat` 실행)

이후에는 **아무것도 누를 필요가 없습니다.** PC에 로그인하면 수집기가 작업 표시줄에 최소화된 채로 켜지고,
롤 내전이 끝나면 자동으로 백업·업로드합니다. (일반/랭크 게임은 건너뜁니다)

## 데이터가 저장되는 곳

`%APPDATA%\naejeon-collector\` ([백업 폴더 열기] 버튼)

| 경로 | 내용 |
|---|---|
| `backups\match_<gameId>.json` | **모든 경기의 원본 백업.** 서버 전송 전에 저장하며 지우지 않습니다 (LCU 원본 응답 포함) |
| `pending\` | 아직 서버에 올라가지 않은 경기. 성공하면 사라집니다 |
| `rejected\` | 서버가 형식 오류로 거부한 경기 |
| `history_export_*.json` | "과거 경기 JSON 저장"으로 만든 파일 |
| `collector_config.json` | 업로드 토큰 (이 PC에만 저장) |

업로드가 실패하면(인터넷 끊김, 서버 오류, 토큰 미설정) 경기는 `pending`에 남고,
수집기가 켜져 있는 동안 5분마다, 그리고 다음 실행 때 **자동으로 재전송**합니다. [실패 건 재전송] 버튼으로 바로 보낼 수도 있습니다.

`backups`, `pending`, 예전 버전의 `match_backup_*.json` 파일은 모두 사이트의
**관리 → 경기 자료 가져오기**에 그대로 넣을 수 있습니다.

## 과거 내전 가져오기 (롤 접속이 가능할 때)

롤 클라이언트는 **로그인한 계정이 참가한** 전적만, 그리고 클라이언트가 보관하는 범위까지만 돌려줍니다.
불러올 때 경기마다 참가자를 확인해 **사람 10명이 5대5로 한 협곡 커스텀(내전)만** 목록에 남깁니다.
봇전·1대1 등 혼자 한 커스텀은 제외되고, 몇 개를 왜 뺐는지 로그에 나옵니다. 조회가 안 되면 **진단** 버튼 결과를 관리자에게 보내세요.

1. 롤 클라이언트에 로그인 (로비 화면까지)
2. 수집기 → **과거 경기 가져오기** 탭 → **경기 불러오기**
3. 둘 중 하나:
   - **선택한 경기 업로드** — 바로 사이트에 반영
   - **선택한 경기 JSON 저장** — `history_export_<닉네임>_<날짜>.json` 으로 저장만 함 (아무것도 선택하지 않으면 전체)

여러 참가자가 각자 JSON을 만들어 관리자에게 보내면, 관리자가 **관리 → 경기 자료 가져오기**에 한꺼번에 넣습니다.
같은 경기는 Riot `gameId`로 한 번만 들어가고, `gameId`가 없는 수기 기록(28경기)과 겹쳐 보이는 경기는
**중복 후보**로 보류돼 관리 화면에서 "합치기 / 따로 등록 / 버리기"를 고릅니다.

## 명령행

```bash
python naejeon-collector.py                    # GUI
python naejeon-collector.py --background       # 최소화 + 바로 수집 시작 (자동 실행이 쓰는 모드)
python naejeon-collector.py --export-history   # 조회 가능한 과거 커스텀 게임 전부를 JSON 으로 저장
python naejeon-collector.py --retry            # 전송 대기 건 재전송
python naejeon-collector.py --set-token        # 업로드 토큰 입력
python naejeon-collector.py --install-autostart / --uninstall-autostart
python naejeon-collector.py --cli / --history  # 콘솔 모드
```

환경변수: `LOL_PATH`(롤 설치 경로), `NAEJEON_SERVER_URL`, `NAEJEON_UPLOAD_TOKEN`, `NAEJEON_DATA_DIR`

## 동작 방식

1. 롤 클라이언트 lockfile 자동 감지 (실패 시 프로세스에서 접속 정보 추출)
2. 게임 진행 중 → 종료 대기
3. 게임 종료 → LCU API로 상세 스탯 추출 (준비 안 됐으면 3초 간격 재시도)
4. **내전만**(소환사의 협곡 사용자 설정 게임, 사람 10명이 5대5): **로컬 백업 → 전송 대기열 → 업로드** (서버가 `gameId`로 중복 방지). 봇전·1대1 등은 건너뜀
5. 업로드 실패분은 자동 재전송

수집 항목: 킬/데스/어시, CS, 골드, 딜량, 받은 피해, 시야 점수, 와드 설치/제거, 오브젝트 피해, CC 점수, 힐/쉴드량, 포탑 피해, 선취점, 멀티킬, 밴,
**아이템·소환사 주문·룬, 팀 오브젝트(포탑·억제기·드래곤·바론·전령)** (게임 직후 매치 상세가 없으면 최대 10분 동안 다시 받아 갱신 업로드),
참가자 **계정 고유 ID(puuid)·태그**(닉네임을 바꿔도 같은 사람으로 이어 집계), **그 시점 솔랭 티어**(기록만, 점수에는 쓰지 않음)

## 문제 해결

| 증상 | 조치 |
|---|---|
| `롤 클라이언트를 찾을 수 없습니다` | 라이엇 런처가 아니라 로그인 후 뜨는 **롤 클라이언트(로비 화면)** 가 켜져 있어야 함 |
| `토큰이 서버의 UPLOAD_SECRET 과 다릅니다` | **업로드 토큰 설정** 에 관리자에게 받은 값을 다시 입력 |
| 과거 경기 조회가 `HTTP 에러: 500` / 커스텀 게임이 없다고 나옴 | 자동으로 작은 범위로 재시도함. 그래도 안 되면 **진단** 버튼 → `──── 진단 결과` 아래를 관리자에게 전달 (비밀값 없음) |
| 업로드가 안 됨 | 경기는 `pending` 폴더에 남아 있고 자동 재전송됨. **실패 건 재전송** 으로 바로 보낼 수도 있음 |
| 새 버전으로 바꾸기 | 수집기 창 닫기 → 사이트에서 ZIP 다시 받아 **같은 폴더**에 덮어쓰기 (토큰·백업은 그대로 유지) |
