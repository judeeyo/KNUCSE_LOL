# 개발 가이드

> 이 저장소의 Next.js 는 16 버전입니다. API·규칙이 예전과 다를 수 있으니 코드 작성 전 `node_modules/next/dist/docs/` 의 해당 문서를 확인하세요 ([AGENTS.md](../AGENTS.md)).

## 실행

```bash
npm ci
```

Supabase 없이 28경기가 든 가짜 DB 로 바로 보기 (관리자 비밀번호 `preview-admin`):

```bash
npm run preview
```

실제 Supabase 로 개발:

```bash
cp .env.example .env.local
```

```bash
npm run dev
```

실제 데이터 사본으로 보고 싶으면 관리 화면에서 받은 백업 파일로 가짜 DB 를 띄웁니다:

```bash
node scripts/dev/mock-supabase.mjs --seed naejeon-backup-2026-11-17.json
```

## 검사

| 명령 | 내용 |
|---|---|
| `npm test` | 단위 테스트 — 통계·점수, 28경기 원본 대조, 가져오기 형식, 중복 판정, 팀 밸런스, 순위 보정 |
| `npm run typecheck` · `npm run lint` | TypeScript · ESLint |
| `npm run build` | 프로덕션 빌드 |
| `npm run test:collector` | 수집기 테스트 (가짜 서버·가짜 롤 클라이언트) |
| `npm run sql:check` | 커밋된 복원 SQL 이 원본 JSON 과 같은지 |
| `scripts/verify-sql.sh` | 로컬 PostgreSQL 에서 SQL 실제 실행 (재실행 중복 0, anon 쓰기 차단) |
| `npm run verify:api` | 가짜 DB + 서버로 업로드·병합·백업·복원·기록 제외·닉네임 연결 흐름 |
| `npm run verify:responsive` | 320/390/768/1280 폭에서 전 화면 레이아웃 자동 점검 (Playwright) |

`verify:api`, `verify:responsive` 는 가짜 DB(`npm run mock:db`)와 빌드된 서버(`npx next start -p 3100`)가 떠 있어야 하며, 환경변수는 [scripts/dev](../scripts/dev) 의 각 파일 상단 주석을 참고하세요.

GitHub Actions(`.github/workflows/ci.yml`)가 `master` 푸시마다 lint · typecheck · test · sql:check · 수집기 테스트 · build 를 돌립니다.

## 배포

`master` 에 푸시하면 Vercel 이 자동 배포합니다. DB 구조를 바꾸는 변경은 `supabase/0N_*.sql` 을 새로 추가하고 [운영 가이드](운영.md#2-처음부터-다시-배포할-때) 의 SQL 표에 적으세요. 코드는 새 열이 없는 DB 에서도 깨지지 않게 작성합니다 (예: `excluded_reason` 은 값이 있을 때만 씀).

## 코드 지도

| 위치 | 역할 |
|---|---|
| `src/app/group/main/page.tsx` | 메인 화면 (탭, 조회 오류 처리) |
| `src/app/group/main/match/[matchId]` · `new` · `admin` | 경기 상세 · 수동 등록 · 관리 화면 |
| `src/app/api/admin` | 관리 작업 (관리자 비밀번호) |
| `src/app/api/upload` | 수집기 업로드 (업로드 토큰) |
| `src/app/api/collector` | 수집기 ZIP 생성 (서버 주소만 넣음) |
| `src/app/api/health` | 배포 상태 점검 |
| `src/lib/stats.ts` | 선수·챔피언·포지션·진영·듀오 통계, 어워즈, 순위 보정, **팀 밸런스** |
| `src/lib/mvp.ts` | 경기 점수(MVP/ACE) |
| `src/lib/profile.ts` · `src/app/group/main/player/[nickname]` | 선수 개인 페이지 집계·화면 |
| `src/lib/list-position.ts` | 화면별 스크롤 위치 기억, "돌아가기" 판단 |
| `src/lib/match-normalize.ts` | DB 행 → 화면용 경기 (미수집 판정, 이름 정규화, 경기 지문) |
| `src/lib/import-parse.ts` | 여러 형식의 자료 해석, 내전 판별 |
| `src/lib/ingest-plan.ts` | 중복 판정, 닉네임 유지 병합 |
| `src/lib/server/ingest.ts` | 가져오기 실행 (부캐·puuid 연결 포함) |
| `src/lib/server/admin-ops.ts` | 관리 작업 (등록·수정·삭제·통합·백업·중복 검토·기록 제외) |
| `src/lib/store.ts` | 화면에서 쓰는 조회(anon) + 관리 API 호출 |
| `collector/collector.py` | 수집기 (GUI·CLI) |
| `scripts/build-legacy-sql.mjs` | 28경기 원본 JSON → 복원 SQL |
| `scripts/dev/` | 가짜 Supabase, API 흐름 검증, 화면 점검, 미리보기 |
