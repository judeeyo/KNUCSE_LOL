# 동작 원리

## 권한

| 하는 일 | 필요한 것 | 경로 |
|---|---|---|
| 통계·기록 **조회** | 없음 (누구나) | 브라우저 → Supabase (anon 키, RLS 로 SELECT 만) |
| 경기 등록·수정·삭제, 기록 제외, 선수 정보, 백업·가져오기 | `ADMIN_PASSWORD` | 브라우저 → `/api/admin` → Supabase (service_role) |
| 수집기 업로드 (경기 **추가·같은 gameId 갱신**만) | `UPLOAD_SECRET` | 수집기 → `/api/upload` → Supabase (service_role) |

- 관리 API 는 `x-admin-password` 헤더(브라우저) 또는 `Authorization: Bearer`(스크립트)로 비밀번호를 받습니다.
- 비밀값이 설정되지 않으면 "누구나 통과"가 아니라 **아무도 쓸 수 없음**(503).
- 수집기 ZIP 에는 서버 주소만 들어가고 비밀값은 없습니다.
- 조회 실패는 빈 기록(0경기)과 구분해 오류 화면 + 다시 시도로 보여 줍니다.

예전 사이트에서 고친 보안 문제: 누구나 anon 키로 DB 를 수정·삭제할 수 있었음, 수집기 ZIP 에 업로드 비밀값이 들어 있었음(미설정 시 공개 기본값), `/api/debug` 가 키 일부와 선수 목록을 노출.

## DB

`matches` 한 행 = 한 경기. 참가자 10명은 `players` JSON 배열.

| 열 | 뜻 |
|---|---|
| `game_id` | Riot gameId (유니크). 수기 기록은 없음 |
| `created_at` | 경기 시각. `time_unknown = true` 면 날짜만 신뢰 |
| `source` | `collector`(실시간) · `history`(클라이언트 과거 전적) · `manual` · `legacy-import`(수기 28경기) · `backup-import` |
| `review_status` | `duplicate_candidate` 면 중복 후보로 보류 (통계 제외) |
| `excluded_reason` | 문구가 있으면 "없던 경기" (통계 제외, 매치 기록에 흑백 표시) |
| `bans` | 밴 챔피언 |

`members` 는 선수 프로필(실명·티어·선호 포지션)과 **부캐 목록(`aliases`)**.

참가자 값 중 자료에 없는 딜량·시야 등은 `null`(미수집)로 저장하고, 화면에는 *미수집*, 평균은 수집된 경기만으로 계산합니다.

## 수집기

1. 롤 클라이언트(LCU, 로컬 API)를 찾아 게임 상태를 감시
2. 경기 종료 → 결과 조회 → **내전인지 확인** → 로컬 백업 → 전송 대기열 → 업로드
3. 실패분은 대기열에 남아 5분마다·다음 실행 때 재전송

**내전 판별**: 사용자 설정 게임 + 소환사의 협곡 + **사람 10명이 5대5**. 봇이 섞이거나 인원이 다르면 제외합니다. 서버도 수집기 자료 중 5대5 10명이 아닌 경기는 거부합니다.

아이템(6칸+장신구)·소환사 주문·핵심 룬·보조 룬 계열·팀 오브젝트(포탑·억제기·드래곤·바론·전령)도 기록합니다. 게임 직후에는 매치 상세가 아직 없을 수 있어, 없으면 30초 간격으로 최대 10분 동안 다시 받아 같은 경기로 갱신 업로드합니다. 팀 오브젝트는 새 DB 열을 만들지 않으려고 `bans` 열(경기 부가 정보 JSON)의 `objectives` 에 둡니다.

업로드할 때 참가자의 **계정 고유 ID(puuid)·태그·그 시점 솔랭 티어**도 기록합니다. 티어는 기록만 하고 점수에는 쓰지 않습니다.

### PC 없이 서버만으로 자동 수집할 수 있나
| 방법 | 지금 내전 방식(로비에서 직접 방 생성) |
|---|---|
| Riot Match-V5 (서버 조회) | 불가 — 토너먼트 코드 없는 사용자 설정 게임은 제공되지 않음 |
| Riot Tournament-V5 | 토너먼트 코드로 만든 방만 가능. Riot 승인 필요, 방 만드는 방식이 바뀜 |
| LCU (이 수집기) | 가능 — 참가자 한 명의 PC 에서 실행 |

그래서 수집기를 "Windows 로그인 시 자동 실행"으로 두는 방식을 씁니다. 롤 계정 비밀번호로 서버가 대신 조회하는 공식 방법은 없고, 계정 공유는 약관 위반이라 구현하지 않습니다.

## 가져오기와 중복 판정

경기 자료(수집기 업로드, 백업, 과거 전적 JSON, DB 내보내기 CSV)는 모두 같은 규칙으로 들어갑니다.

1. 같은 **id** → 건너뜀 (백업을 여러 번 넣어도 안전)
2. 같은 **gameId** → 수집기 자료면 갱신, 복원 자료면 건너뜀
3. gameId 없는 기존 기록(수기)과 **10명의 챔피언·K/D/A 가 모두 같음** → **자동으로 합침**
   - 기존 id·닉네임 유지, 딜량·시야·밴·gameId·정확한 시각 채움
   - 다른 Riot 닉네임은 그 사람의 부캐로 자동 등록 (이미 별도 선수면 알려만 줌)
4. 날짜 ±1일 + 챔피언 8개 이상 겹침 → **중복 후보**로 보류 (관리자가 검토)
5. 그 외 → 새 경기

닉네임 처리: 부캐는 본캐로 바꿔 저장하고, **같은 puuid 가 새 닉네임으로 오면 예전 닉네임으로 이어 붙이고 새 닉네임을 부캐로 등록**합니다 (puuid 를 기록하는 새 수집기부터).

## 점수

### 경기 점수 (MVP/ACE, 0~10)
10명 전체 대비 평가, 포지션별 가중치(서폿은 CS 대신 시야·CC 등), 같은 라인 상대와의 1:1 비교, 라인전 골드 차 보정. 게임 평균이 5.0. 산정식이 바뀌어도 과거 경기에 똑같이 적용되도록 읽을 때마다 다시 계산합니다. (`src/lib/mvp.ts`)

**MVP·ACE 는 "같은 라인·같은 승패 평균 대비"로 고릅니다.** 점수 숫자를 그대로 비교하면 라인마다 평균이 달라 치우칩니다 — 진 팀 서포터는 팀 킬이 적어 킬관여율이 쉽게 높고 받은 피해도 점수가 돼서, 상세 데이터 22경기 중 ACE 10번이 서포터에게 갔습니다(진 팀 서포터 평균 4.45점, 다른 라인 3.6~3.7점). 그래서 각 선수 점수를 같은 라인·같은 승패·같은 자료 종류(상세/수기) 경기들의 평균·표준편차로 표준화해, 이긴 팀에서 가장 높은 사람이 MVP, 진 팀에서 가장 높은 사람이 ACE 입니다. 표본이 8판 미만인 칸은 라인 구분 없이 같은 승패 전체로 대신합니다. 화면에 보이는 점수 숫자는 그대로입니다.

### 종합 점수 (선수별 성적의 "점수", 0~100)
그룹 내 백분위 가중합: 승률(판수 보정) 30% + MVP/ACE 15% + KDA 10% + 킬관여 10% + 분당CS 10% + 시야 10% + 골드당 딜 10% + 판수 5%, 판수가 적으면 신뢰도 계수로 감점. 미수집 지표는 중립(50) 처리.

### 순위 표시 보정 (마지막 참가)
- 마지막 참가 후 30일까지 그대로, 30~90일은 순위 점수를 선형으로 최대 15% 감점(*휴식 감점*)
- 90일 이상이면 정렬과 무관하게 맨 아래, ⚠️ *3개월+ 미참여*
- 순위 표시에만 적용, 팀 밸런스 실력 점수에는 쓰지 않음

### 진영별 통계
블루/레드가 확실한 경기만 집계합니다. 예전 사이트에서 옮긴 수기 28경기는 원본에 "팀1/팀2"만 있어 실제 진영을 알 수 없으므로 제외합니다 (Riot 데이터와 합쳐진 경기는 포함).

### 리더보드 최소 판수
전체 경기 수의 20% (최소 1판, 최대 21판). 50경기면 10판.

## 라이벌 (실험실) — `src/lib/rivalry.ts`

- **같은 라인 맞대결만** 셈: 한 경기에서 블루·레드의 같은 라인 두 사람이 한 쌍. 라인 정보는 수집기 로비 순서·수기 기록 기준이라 라인 스왑이 있었던 판은 틀릴 수 있음
- 목록: 맞대결 3판 이상. 정렬 = (최근일수록 무겁게 센 판수(반감기 60일) + 판수×0.15) × (0.5 + 접전도), 접전도 = 1 − |보정 승률 − 0.5|×2, 보정 승률 = (승+2)/(판+4)
- 칭호: 숙명의 라이벌(8판+, 40~60%), ○○ 우세(6판+, 70%+), ○연승 중(3+), 복수전(직전 패자)
- 지표 비교 `METRICS`: KDA·데스·분당 CS·분당 골드·킬관여(팀 킬 대비, 수기 기록 포함)·팀 내 딜 비중·분당 시야(이 둘은 수기 기록 제외). 두 사람 모두 2판 이상 있을 때 차이가 기준(KDA 0.3, 데스 0.4, CS 0.3, 골드 15, 킬관여 3%p, 딜 비중 2%p, 시야 0.1) 이상이면 우세/열세, 아니면 비슷. **평소** = 그 선수의 같은 라인 경기 평균(3판 미만이면 전체 경기)
- 라인전 참고 문장 `buildTips` (기준을 넘을 때만, 영향 큰 순 최대 5개, 한 종류 최대 2개)
  | 종류 | 조건 (평소 대비) |
  |---|---|
  | 맞대결 | 데스 ±1, 분당 CS −0.6, 킬관여 ±8%p, 딜 비중 −4%p |
  | 상대 챔피언 (그 챔피언 상대 2판+) | 분당 CS ±0.7, 데스 +1.5 |
  | 내 챔피언 (2판+) | 데스 +1.5, 딜 비중 −4%p, 분당 CS −0.7, 킬관여 +10%p, KDA +1 |
  | 픽 | 상대 챔피언 전승(3판+ "밴 고려"), 내 챔피언 전승(KDA 문장이 있으면 생략) |
  | 초반 | 퍼스트 블러드 40% 이상 (수기 기록 제외) |
  2판짜리 문장은 우연일 수 있어 판수를 함께 적음
- 특집 묶음 `FEATURED_GROUPS`: 탑 삼국지(뽀스탈게요·DoYouKnowIMO·우효원). 아이디 통합으로 이름이 바뀌면 여기도 수정
- 카톡 카드 `rivalry/[a]/[b]/opengraph-image.tsx`: 주 챔피언 일러스트(Data Dragon `centered` 스플래시)·아이콘·전적·칭호·최근 10판

## 팀 밸런스

**선수 점수 (0~10)**
- 솔랭 티어 **없음**(기본): 내전 성적만. 성적 = 종합 점수에서 신뢰도 계수를 걷어낸 값을, 판수가 적을수록 **평균 5점 쪽으로** 수렴 (처음 온 사람을 약하게 보지 않음)
- 솔랭 티어 **있음**: 티어 × (100−w)% + 내전 성적 × w%, w = 0.65·√(판수/(판수+5))
- 티어: 아이언 1 ~ 챌린저 9.2, 디비전당 0.25. `다이아 2` · `다이아2` · `D2` · `gold 3` 등 인식

**편성**
- 10명이면 5명 조합 126가지(블루/레드만 바뀐 것은 하나로)를 모두 계산
- 목표 = 팀 점수 합 차이 + 포지션 불만족도. 선호 포지션 1순위 1.0, 2순위 0.8 … 비선호 0.1 (선호 미설정자는 0.5). 선호 포지션이 없으면 전적(라인별 판수)에서 자동으로 정함
- 목표가 좋은 순서로 서로 다른 조합 **상위 3개** → 1안·2안·3안 (많으면 고르기 어렵다는 의견으로 5→3)
- 조건: 두 사람 같은 팀/다른 팀 고정, 최근 3경기 팀 명단과 똑같은 편성 제외(선택)

**짝 편성** (`balancePairedTeams`, 화면 `balance-pair-editor.tsx`)
- 10명을 비슷한 실력끼리 5짝으로 묶으면 각 짝은 반드시 다른 팀. 2⁵=32가지 중 거울상 제외 16가지를 점수 차이 우선(동점이면 포지션 만족도)으로 정렬해 상위 3개만 표시
- 짝 지정: 선수 칩을 차례로 두 번 누르면 한 짝. **점수순 자동 짝**은 남은 선수를 점수 순 이웃끼리(1-2등, 3-4등…) 묶음

**AI 판정 (우세/열세)** — `src/lib/team-analysis.ts`
- 챗봇(LLM)을 부르지 않고 내전 기록으로 계산. 아래 요소를 로짓(log-odds)으로 더해 블루 예상 승률을 냄
  | 요소 | 계수 |
  |---|---|
  | 팀 점수 합 차이 | 1점당 0.35 |
  | 비선호 라인 배정 인원 차이 | 1명당 0.12 |
  | 팀원 궁합: 같은 팀 2판 이상 쌍의 (보정 승률 − 50%) 합 | 0.6 |
  | 맞라인 상대 전적: 같은 라인 2판 이상 (보정 승률 − 50%) | 0.4 |
- 보정 승률 = (승 + 1.5) / (판 + 3) — 판수가 적으면 50% 쪽으로
- 예상 승률은 25~75% 로 제한. 50%와 차이 3%p 미만 **박빙**, 8%p 미만 **약간 우세**, 그 이상 **우세**
- 영향이 큰 이유 최대 3개를 함께 표시. 5판 미만 선수가 있으면 신뢰도 낮음 안내
- 계수는 표본이 적어 보수적으로 정한 값이며 아직 검증 전 ([점수모델_작업관리](점수모델_작업관리.md#팀-편성-화면과-ai-판정))

**검증**: 51경기로 "각 경기 직전까지의 기록으로 승리 팀 맞히기"를 해 보면 41판 중 22판(54%)으로, 표본이 적어 아직 예측력을 입증할 수 없습니다(단순 승률·Elo 도 46~54%). 경기가 쌓이면 다시 확인할 예정입니다.
