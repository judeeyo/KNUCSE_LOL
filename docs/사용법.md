# 사용법 (내전 참가자용)

사이트: https://knucse-lol.vercel.app/group/main — 로그인 없이 누구나 볼 수 있습니다.

## 탭 설명

| 탭 | 내용 |
|---|---|
| **선수별 성적** | 리더보드. 상단에 어워즈(최근 20경기 기준). 표의 열 제목을 누르면 정렬, 행을 누르면 상세 |
| **챔피언 승률** | 챔피언별 판수·승률·밴. 라인별로 볼 수 있음 |
| **포지션별 순위** | 탑~서폿 각 라인에서 5판 이상 한 선수의 라인 성적 순위 |
| **진영별 통계** | 블루/레드 승률 비교 |
| **듀오 상성** | 같은 팀일 때 잘 맞는 / 안 맞는 조합 |
| **매치 기록** | 날짜별 경기 카드. 누르면 경기 상세 — 소환사 주문·핵심 룬·아이템, 팀 오브젝트(포탑·억제기·드래곤·바론·전령), 킬관여·팀 딜 비중 (새 수집기로 올린 경기부터). 돌아가기·뒤로가기 하면 보던 위치로 |
| **선수 정보** | 실명·선호 포지션·부캐 관리 (수정은 관리자) |
| **팀 밸런스** | 오늘 참가자를 골라 팀 짜기 |

## 표에서 자주 보는 표시

| 표시 | 뜻 |
|---|---|
| **미수집** | 그 경기 자료에 없는 값. 예전 수기 기록 28경기는 딜량·시야점수가 없음. 0점 처리하지 않고 평균에서 뺌 |
| **마지막 참가** | 마지막으로 내전에 나온 날 |
| **휴식 감점** | 마지막 참가 후 한 달이 지나 순위 점수를 조금 낮춤(최대 15%) |
| ⚠️ **3개월+ 미참여** | 90일 이상 참가하지 않아 순위 맨 아래로 내림 |
| 🔥 / 💩 | 최근 폼 상승 / 하락 (최근 5경기 승률 vs 그 이전) |
| 흑백 카드 + 흰 글씨(예: *Zeus's Law*) | **없던 경기**로 처리된 경기. 기록에는 보이지만 어떤 통계에도 들어가지 않음 |
| 수기 기록 · 시각 미상 | 예전 사이트에서 옮겨 온 경기. 날짜만 정확함 |

## 선수 페이지

선수 이름(경기 상세, 포지션별 순위, 선수 정보)이나 리더보드 상세 창의 **경기 기록·승률 추이·상대 전적 보기**를 누르면 그 선수 페이지가 열립니다. 주소(`…/group/main/player/닉네임`)를 그대로 공유할 수 있고, 부캐 이름으로 열어도 본캐 페이지로 갑니다.

- **누적 승률 추이** — 경기마다 누적 승률. 그래프에 마우스를 올리거나 누르면 그 경기 날짜·결과
- **요약** — 경기·승률·KDA·MVP, 평균 지표, 최근 전적, 라인별 전적, 챔피언 풀
- **함께하면** — 같은 팀일 때 잘 이기는 / 잘 지는 팀원
- **상대로 만나면** — 상대 팀일 때 내가 강한 상대 / 천적
- **맞라인 상대 전적** — 같은 라인 맞상대별 승패
- **경기 기록** — 최근 경기부터 (승패, 챔피언, 라인, KDA, CS, 팀 내 딜 비중, 경기 점수). 누르면 경기 상세

## 카톡으로 공유하기

경기 상세나 선수 페이지 주소를 단톡에 붙여넣으면 미리보기가 뜹니다.
- **경기 링크**: 날짜·게임 시간, 양 팀 챔피언·닉네임·KDA, 스코어, MVP/ACE가 들어간 카드 (기록 제외 경기는 문구가 덮여 보임)
- **선수 링크**: "○전 ○승 ○패 · 승률 · KDA"
- 카톡은 미리보기를 한동안 저장해 두므로, 경기를 고친 직후에는 예전 카드가 보일 수 있습니다.

리더보드는 기본적으로 **전체 경기 수의 20% 이상**(최소 1판, 최대 21판) 뛴 사람만 보입니다. 오른쪽 **전체 N명 보기**로 모두 볼 수 있습니다.

## 팀 밸런스 쓰는 법

1. **팀 밸런스** 탭에서 오늘 참가자를 고릅니다 (최대 10명, 짝수).
2. 필요하면 **편성 옵션**
   - *최근 3경기와 같은 팀 구성 피하기* — 같은 멤버로 연달아 할 때 매번 같은 팀이 나오지 않게 (기본 꺼짐)
   - *두 사람 고정* — 두 명을 골라 **같은 팀** 또는 **다른 팀**으로 묶기 (여러 쌍 가능)
3. **팀 짜기 (10명)** 버튼 → 잠깐 "팀 짜는 중…"이 뜬 뒤 결과 위치로 화면이 이동합니다.
4. 추천 편성 **1안·2안·3안** 중에서 고릅니다. 각 안에는 점수 차이·포지션 만족도·우세 팀이 같이 나옵니다.
5. **AI 판정** — 블루/레드 예상 승률 막대와 *박빙 · 약간 우세 · 우세*, 그렇게 본 이유(점수 합, 비선호 라인, 팀원 궁합, 맞라인 상대 전적) 최대 3개.
   내전 기록으로 계산한 예상치라 판수가 적은 사람이 있으면 정확도가 낮습니다.

### 짝으로 편성하기
실력이 비슷한 두 명씩 짝을 지어, 짝끼리는 무조건 다른 팀이 되게 하는 방식입니다.
1. 위쪽 **밸런스 짝으로 편성** 선택 → 참가자 10명 선택
2. **밸런스 짝** 칸에서 선수 칩을 두 명 차례로 누르면 한 짝 (잘못 누르면 같은 칩을 다시 눌러 취소, 만든 짝은 ✕로 풀기)
   - **점수순 자동 짝**: 점수 순으로 이웃끼리 자동으로 묶음. 몇 짝만 직접 정하고 나머지를 자동으로 채울 수도 있음
   - 짝 옆 `±0.4` 는 두 사람 점수 차이 (1점이 넘으면 노란색)
3. **짝으로 팀 짜기** → 각 짝을 블루/레드로 나누는 경우 중 상위 3개 추천

점수에 마우스를 올리면 계산 근거가 보입니다. 공식은 [동작원리](동작원리.md#팀-밸런스).

## 수집기 설치 (더블클릭 한 번)

관리자에게 **토큰 포함 수집기** ZIP 을 받아 압축을 풀고 `내전수집기.bat` 을 더블클릭하면 끝입니다.
Python 자동 설치, 로그인 시 자동 실행, 수집 시작, 과거 내전 동기화까지 알아서 합니다. 자세한 내용은 [collector/README.md](../collector/README.md).

## (예전 방식) 수집기 직접 설정

내전하는 날 **참가자 중 한 명만** 수집기가 켜져 있으면 그 경기가 자동으로 올라갑니다. 여러 명이 켜도 같은 경기는 한 번만 기록됩니다.

1. [python.org/downloads](https://python.org/downloads) 에서 Python 설치 — **"Add Python to PATH" 체크**
2. 사이트 상단 **수집기** 버튼 → ZIP을 지워지지 않을 폴더에 풀기 (예: `문서\내전수집기`)
3. `내전수집기.bat` 실행 → **업로드 토큰 설정** → 관리자에게 받은 토큰 입력
   → 로그에 `✅ 서버 연결 및 토큰 확인 완료`
4. **Windows 로그인 시 자동 실행** 체크

이후에는 아무것도 누를 필요 없습니다. 자세한 내용·문제 해결은 [collector/README.md](../collector/README.md).

> 업로드 토큰은 관리자 비밀번호와 다릅니다. 토큰으로는 경기를 **추가**만 할 수 있고 수정·삭제는 할 수 없습니다.

## 자주 묻는 것

**Q. 기록을 불러오지 못했다고 떠요.**
기록이 사라진 게 아니라 DB 조회가 실패한 상태입니다. **다시 시도**를 누르세요. 계속되면 관리자에게 알려 주세요 ([운영 › 문제 해결](운영.md#5-문제-해결)).

**Q. 내 닉네임이 두 개로 나와요 / 닉네임을 바꿨어요.**
관리자에게 알려 주면 **아이디 통합**으로 합칩니다. 새 수집기로 올린 경기는 계정 고유 ID가 같이 기록돼 닉네임을 바꿔도 자동으로 이어집니다.

**Q. 이 경기는 빼고 싶어요.**
관리자가 **기록 제외**로 "없던 경기" 처리할 수 있습니다 (지우지 않고 흑백으로 남김).
